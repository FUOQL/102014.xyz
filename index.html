你好，我是李清波，一名计算机科学与技术专业的深度患者。不是那种「会写几行 Python 就自称程序员」的速成选手——我是从晶体管逻辑门开始啃、从 gcc -S 看汇编输出、从 Linux 0.11 源码一行行读过来的苦行僧。

数据结构与算法于我而言不是八股文，是肌肉记忆。能在白板上徒手写出红黑树 rotate，也能在系统设计面试时从 C10K 聊到 C10M，从 epoll 聊到 io_uring，从单体聊到 CQRS + Event Sourcing，面不改色。

我相信真正的工程师不挑语言。C 的锋利、Rust 的严苛、Go 的务实、Python 的灵巧、TypeScript 的表达力——每种语言都是一把不同形状的刀，关键是你握刀的手够不够稳。而我的手，很稳。

做过高并发秒杀系统，QPS 从 800 压到 8000，瓶颈不在代码在数据库；写过自研 RPC 框架，协议层手搓的，序列化比 Protobuf 还快 15%；带过五人小团队三个月从零交付一套 SaaS 平台，甲方验收那天说「这次终于没踩坑」。

目前深耕全栈架构设计与系统性能优化。白天写代码，晚上读论文，周末给开源项目提 PR。不是职业，是呼吸。

// 我的信条

代码是有价值观的。

追求本质

不满足于"能跑就行"。每个抽象都追问为什么，每层封装都计算代价。我写的不是特性，是负债表上最小的一行。

不设边界

前端工程师？后端工程师？这些标签对我来说毫无意义。我写 React 组件像写 Java Service 一样严谨，写 SQL 像写诗一样斟酌索引。

手上见真章

文档写得好不如代码能跑。讨论三天架构不如花三小时写一个可工作的原型。Talk is cheap, show me the diff.

极致性能

首屏加载超过一秒？P99 延迟抖动？GC 停顿影响吞吐？在我这里没有「差不多」。性能优化的终点是你再往下优化边际收益为零的那一刻。

技术布道

写博客、做分享、带新人。一个好的技术方案应该能在一张餐巾纸上讲清楚。我享受把复杂的系统画成三张图、让非技术同事也能听懂的成就感。

终身学习

每周啃一篇系统领域顶会论文，每季度深入一门新语言。两年掌握了 Rust 的所有权和 borrow checker，三年把分布式一致性协议吃透到能徒手推演 Raft 选举过程。学无止境。
